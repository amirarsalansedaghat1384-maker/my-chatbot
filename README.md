# چت‌بات ساده با Claude API

## مراحل راه‌اندازی

### ۱. گرفتن کلید API
1. به [console.anthropic.com](https://console.anthropic.com) برو
2. ثبت‌نام کن و به بخش **API Keys** برو
3. یک کلید جدید بساز و کپی کن

### ۲. نصب پیش‌نیازها
در همین پوشه، این دستور رو در ترمینال اجرا کن:

```bash
pip install -r requirements.txt
```

### ۳. ست کردن کلید API
بهترین روش، ست کردن کلید به عنوان متغیر محیطی است:

**در Mac/Linux:**
```bash
export ANTHROPIC_API_KEY="کلید-شما-اینجا"
```

**در Windows (PowerShell):**
```powershell
$env:ANTHROPIC_API_KEY="کلید-شما-اینجا"
```

یا اینکه مستقیماً داخل فایل `app.py` در خط:
```python
API_KEY = os.environ.get("ANTHROPIC_API_KEY", "کلید-API-خودتو-اینجا-بگذار")
```
به‌جای `"کلید-API-خودتو-اینجا-بگذار"` کلید خودت رو بگذار.

⚠️ **توجه:** اگه می‌خوای این فایل رو جایی آپلود کنی (مثل گیت‌هاب)، هیچ‌وقت کلید API رو مستقیم داخل کد نگه ندار — از متغیر محیطی استفاده کن.

### ۴. اجرای برنامه
```bash
python app.py
```

سپس در مرورگر برو به:
```
http://localhost:5000
```

## قابلیت‌های فعلی
- چت متنی ساده با Claude
- حفظ تاریخچه مکالمه (در حافظه، فقط برای یک نشست)
- رابط کاربری وب ساده و راست‌چین (فارسی)

## ایده‌هایی برای توسعه بعدی
- ذخیره تاریخچه در دیتابیس (مثل SQLite)
- پشتیبانی از چند کاربر همزمان
- اضافه کردن قابلیت آپلود فایل / تصویر
- استریم کردن پاسخ‌ها (تایپ تدریجی مثل ChatGPT)
- اضافه کردن RAG برای دانش تخصصی خودت
